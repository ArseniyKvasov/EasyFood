Как считается

Сначала базовый обмен по формуле Миффлина-Сан Жеора: 10 × вес + 6,25 × рост − 5 × возраст. Для женщин вычитается 161, для мужчин прибавляется 5. Дальше результат умножается на коэффициент активности: 1,2 для сидячей, 1,375 для одной-двух тренировок, 1,55 для трёх-пяти, 1,725 для ежедневных.

Цель меняет итог: минус 15% для похудения, плюс 10% для набора. Ниже 1 200 ккал для женщин и 1 500 для мужчин калькулятор не опускается. Белки считаются как 1,7 г на килограмм веса, жиры - 0,9 г, углеводы получаются остатком калорий.

Это оценка, а не медицинская рекомендация. При заболеваниях, беременности и расстройствах пищевого поведения расчёт нужно согласовать с врачом.
